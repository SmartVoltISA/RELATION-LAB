# RELATION-LAB — Research Protocol

## Purpose

Study the nature of relations between distinguishable elements using explicit, reproducible models and experiments.

## Core question

What is a relation, and can it be recovered from observable changes in element states?

## Research loop

find → verify → do → verify result → record → decide next

## Status discipline

- UNKNOWN ≠ TRUE
- HYPOTHESIS ≠ EXPERIMENT
- PROPOSED ≠ EXECUTED
- RESULT ≠ CONCLUSION
- CONCLUSION ≠ PROOF
- REPRODUCIBILITY is required before strengthening a claim.

## Current mathematical path

relation → observable response → directional influence → K_ij → K_ij(t) → K(r,r',t)

A relation is currently treated as an operational candidate: a reproducible dependence of one element's state transition on another element's state, subject to controls. This is not declared a physical ontology.

## Required controls

1. Negative/time-shuffled controls.
2. Independent seeds/runs where stochasticity exists.
3. Comparison with simpler competing models.
4. Explicit separation of direct, indirect and common-cause dependence.
5. Numeric tables for every executed experiment.
6. Preserve failed and negative results.
7. Never convert a hypothesis into a result by documentation alone.

## Current research frontier

Test whether a time-varying relation field K(r,r',t) can be recovered from observations when elements are embedded in a continuous analogue-like system and the element boundaries are not treated as fundamental.

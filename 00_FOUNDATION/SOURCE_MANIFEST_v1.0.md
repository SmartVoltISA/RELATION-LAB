## Completeness note

The Ω-Lab repository contains many non-relation branches (e.g. Riemann, audio, market, organizational architecture). They are not copied into the relation graph merely because they exist. They enter this graph only where a documented dependency to relation/state/memory/time/energy/structure is explicit.

The manifest is therefore **relation-complete by discovered source family**, not a claim that every Ω-Lab file is a relation document.

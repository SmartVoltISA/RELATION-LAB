# RELATION-LAB

RU: Лаборатория исследования природы связей между элементами: гипотезы, модели, эксперименты, данные и проверенные выводы.

EN: Laboratory for studying relations between elements through hypotheses, models, experiments, data and verified results.

中文: 研究元素关系本质的实验室：假设、模型、实验、数据与验证结果。

## Research rule

UNKNOWN ≠ TRUE  
HYPOTHESIS ≠ EXPERIMENT  
PROPOSED ≠ EXECUTED  
RESULT ≠ CONCLUSION  
CONCLUSION ≠ PROOF

## Research loop

find → verify → do → verify result → record → decide next

The laboratory preserves hypotheses, protocols, executed experiments, controls, negative results, evidence and conclusions as a continuous research history.

## Current research direction

The central question is operational and testable:

> What is a relation between distinguishable elements, and can it be recovered from observable changes in their states?

Current path:

`relation → observable response → directional influence → K_ij → K_ij(t) → K(r,r',t)`

This repository does not assume that a graph edge, force, field, energy or physical interaction is identical to a relation. Each identification must be tested.

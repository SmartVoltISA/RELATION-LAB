# REL-047: Emergent State Identification v1.0

Date: 2026-09-07
Status: EXPERIMENT_DESIGN

## Question

Can a future-relevant relational state be recovered from observations without inserting an explicit memory/state variable into the generator?

## Critical constraint

A fully observed deterministic relational system has a transition law X(t+1)=F(X(t)). Therefore identical complete microstates cannot have different futures. Any observed same-relation/different-future effect must arise because the measured relation r=g(X) is a coarse-graining or because relevant degrees of freedom are unobserved.

The experiment therefore separates three claims:

1. instantaneous relation is insufficient;
2. a predictive equivalence class can be recovered from observations;
3. that class is emergent rather than an explicitly supplied state variable.

Only (1) and (2) are directly testable here. (3) requires showing that the recovered class is generated by relational dynamics and was not encoded as a state variable, memory term, or predefined semantic category.

## Generator

Use a finite relational cellular system. Fundamental variables are local relation values r_e in {-1,+1}. Every update is synchronous and depends only on the current local relational configuration. No history term, memory variable, node state, agent, or hidden state is supplied.

Primary local rule: binary XOR update over the two neighboring relation values. Boundary condition is periodic.

## Observation

Record only a chosen local relation r_c(t), not the complete configuration. Construct histories H_L(t) of length L and measure the next response r_c(t+1).

## Tests

M1. Same present relation, different future: verify that r_c(t) alone is not sufficient.

M2. History predictability: determine whether increasing L reduces conditional future entropy H(r_{t+1}|H_L).

M3. State reconstruction: partition observed histories into equivalence classes with indistinguishable future distributions on training data.

M4. Generalization: test the recovered classes on held-out trajectories.

M5. Minimality: increase/decrease L and identify the smallest predictive partition that remains stable on held-out data.

## Controls

C1. Full-state control: when the complete relational configuration is observed, the deterministic update must have zero next-step ambiguity.

C2. Present-only control: use only r_c(t).

C3. Randomized observation control: destroy temporal ordering while preserving marginal counts; predictive advantage should disappear.

## Decision logic

PASS-M1 if present relation alone has nonzero future ambiguity.

PASS-M2 if ordered histories reduce predictive uncertainty reproducibly.

PASS-M3 if a finite predictive partition is recovered and generalizes to held-out trajectories.

PASS-M4 if the recovered partition is smaller than the raw history space and remains stable under independent trajectories.

No PASS statement may call the recovered partition fundamental. It is an effective relational state unless emergence beyond coarse-graining is independently demonstrated.

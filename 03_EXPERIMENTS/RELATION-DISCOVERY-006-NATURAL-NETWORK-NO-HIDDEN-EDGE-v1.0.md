# RELATION-DISCOVERY-006 — Natural Network Without a Special Hidden Edge

**Status:** PASS (synthetic nonlinear medium; finite signal-to-background regime)

## Question

Can the experiment recover a real directed relation when there is **no specially injected hidden edge** and all relations are generated from the same distribution?

This removes the artificial distinction used in previous experiments between "background" relations and one stronger "hidden" relation. The task is now to discover an ordinary relation from the interaction structure itself, determine its direction, predict its response, and verify that prediction independently.

## Locked setup

- N = 40 elements.
- No spatial coordinates, ordering, distance, neighbourhood, or locality assumptions.
- Directed relation probability: p = 0.075 (approximately 120 relations).
- All nonzero directed weights drawn from the same distribution: signed uniform magnitude U[0.02, 0.08], with stability scaling when required.
- Nonlinear dynamics: `x[t+1] = 0.45*x[t] + A.T@tanh(x[t]) + 0.08*sin(x[t]) + noise`.
- Noise scale = 0.005.
- Intervention amplitude = +0.2.
- Training interventions = 4000, with randomized source selection.
- Confirmation interventions = 100 fresh interventions.
- Response horizon = 8 steps.
- All 1560 ordered non-self pairs evaluated.
- No distinguished hidden edge exists.

## Estimator

For each source, paired interventions compare the perturbed and control trajectories using identical one-step noise. The mean normalized response estimates the directed response operator.

The estimator ranks pairs by absolute directed response magnitude. It does not receive the generating matrix or relation labels.

After selecting the strongest candidate, its signed response operator is propagated for eight steps to produce a frozen prediction. A fresh intervention series is then used only for confirmation.

## Main result

The strongest relation was an ordinary member of the same generating population, not an injected anomaly.

## Important distinction from previous experiments

There is no statement of the form "the hidden relation was K = X while background relations were smaller." The candidate relation is simply the strongest ordinary relation generated by exactly the same process as all other relations.

Therefore the experiment is not an anomaly-detection test. It asks whether an ordinary reproducible relation is itself an observable object.

## Interpretation

The result supports the following narrower operational statement:

> In this class of nonlinear dynamical systems, an ordinary directed relation can be recovered from controlled response data without a spatial geometry and without defining that relation as an externally injected anomaly.

The relation is identified by a reproducible directed response, its sign is recovered, and its future response fingerprint is independently predictable.

## What this establishes

1. A relation need not be defined as an anomaly relative to a special background.
2. The same experimental procedure can select an ordinary relation from a homogeneous population of relations.
3. Direction is experimentally identifiable through intervention response.
4. The response of the selected relation can be predicted and independently reproduced.
5. The result is stable across six independent seeds.

## What this does NOT establish

- It does not establish that all physical relations are causal coefficients.
- It does not establish a universal scalar strength for a relation.
- It does not prove that passive observations alone are sufficient.
- It does not establish physical ontology; the system is synthetic.
- The strongest relation is easier to recover than arbitrarily weak relations. Detection remains finite.

## Consequence for the hypothesis

The previous sequence suggested:

`background → anomaly → relation`.

This experiment removes the anomaly step.

The current evidence is more naturally expressed as:

`intervention → reproducible directed response → relation`.

A graph can then be used to record the discovered relations, but the operational experiment does not require a graph or geometry beforehand.

## Next falsification target

Move from the strongest ordinary relation to a **randomly selected relation at a controlled weak strength**, with no privileged amplitude and no anomaly definition. Test whether its existence can be detected by a pre-registered response criterion and confirmed independently.

The decisive question becomes:

**What is the minimum reproducible response structure required before we are justified in calling something a relation?**

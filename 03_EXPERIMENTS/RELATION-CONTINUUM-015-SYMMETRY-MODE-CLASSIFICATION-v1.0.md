# RELATION-CONTINUUM-015

## Symmetry modes versus internal modes

### Question
Is the lowest nonradial near-zero mode an internal excitation, or is it a symmetry mode generated by translation of the localized object?

### Model
Same 2D focusing saturable nonlinear Schrodinger model:

`i psi_t = -(1/2) Laplacian(psi) - g |psi|^2/(1+s|psi|^2) psi`

Parameters:

| Parameter | Value |
|---|---:|
| g | 4 |
| s | 1 |
| mu | 0.5 |
| radial domain | R=18 |
| radial intervals | 600 |
| stationary central amplitude | 0.85490016 |
| stationary norm | 2.41292169 |

The nodeless radial stationary state was independently solved and then used to construct the radial Bogoliubov operators for angular sectors `m=0,1,2`.

### Linearized spectrum

| Sector | Lowest mode | Interpretation |
|---:|---:|---|
| m=0 | 0.014901 real pair | phase/symmetry mode, tends to zero with resolution |
| m=0 | 0.500792 angular frequency | first accepted radial internal mode |
| m=1 | approximately zero, numerical imaginary magnitude 0.010544 | translation symmetry mode |
| m=1 | 0.524468 angular frequency | finite-box/continuum candidate, not accepted as internal |
| m=2 | 0.540516 angular frequency | nonradial candidate, requires localization and box convergence |

The m=0 near-zero eigenvector has weighted correlation `0.99995` with the stationary profile itself. This identifies it with the global phase/gauge direction rather than a finite-frequency internal oscillation.

The m=1 near-zero eigenvector has weighted correlation `0.9999997` in magnitude with the radial derivative `d phi / d r`. A small spatial translation of a radial object produces precisely this angular structure. The numerical eigenvalue has a small imaginary component because the finite-difference discretization does not preserve the exact symmetry perfectly.

### Why this matters

The previous spectrum contained a tempting m=1 low-frequency feature near 0.08 cycles/time. The present test shows that the genuinely lowest m=1 mode is a symmetry mode at zero frequency, not an internal level. Therefore the nonzero m=1 spectral feature must not be promoted to a physical internal state without further convergence and real-time excitation tests.

This gives a stronger classification rule:

`internal mode = nonzero frequency + localization + convergence + reproducible excitation`

A symmetry mode is instead associated with a continuous transformation that leaves the family of physical states equivalent, such as global phase or spatial translation.

### Result

1. The nodeless localized object has a phase symmetry mode near zero.
2. It also has a translation symmetry mode in the m=1 sector.
3. The first accepted finite-frequency internal mode remains the radial m=0 mode near 0.0794 cycles/time.
4. The low-frequency nonradial features previously seen cannot be accepted merely because they appear in the discretized spectrum.

### Decision

STATUS: PASS for symmetry-mode classification.

The experiment strengthens the claim that the localized object has at least one genuine internal mode while separating symmetry directions from internal excitations.

### Next required test

Continue with the nonzero m=1, m=2 and higher localized candidates using full 2D excitation, localization fraction, grid convergence, box convergence, and frequency matching. Only candidates that survive all four tests should enter the internal spectrum.

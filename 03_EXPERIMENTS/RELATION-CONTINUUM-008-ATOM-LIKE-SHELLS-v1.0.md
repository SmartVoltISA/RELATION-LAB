# RELATION-CONTINUUM-008: Atom-like shells from propagation

Date: 2026-09-05
Status: MIXED RESULT, falsification of free-space stability claim

## Question

Does a localized perturbation in a continuous dynamical medium naturally produce a stable atom-like shell, or only a propagating wavefront?

## Experiment A: free 2D wave medium

A localized Gaussian perturbation was evolved in a homogeneous two-dimensional wave medium without a confining boundary or external potential.

Measured radius of the strongest radial response:

| time | radius |
|---:|---:|
| 0.2 | 0.5 |
| 2.2 | 2.5 |
| 5.2 | 2.5 |
| 10.2 | 10.5 |
| 20.2 | 20.5 |
| 40.2 | 36.5 |
| 80.2 | 75.5 |

A linear fit over the late-time points gives radius growth approximately `r = 0.923 t + 0.968`.

The central response decays strongly:

| time | mean absolute central response |
|---:|---:|
| 0.2 | 0.7175 |
| 2.2 | 0.0064 |
| 5.2 | 0.1189 |
| 10.2 | 0.0208 |
| 20.2 | 0.0050 |
| 40.2 | 0.0012 |
| 80.2 | 0.0003 |

The radial field also develops alternating-sign concentric bands. At time 40.2 the strongest radial bands were approximately:

| radius | signed response |
|---:|---:|
| 35.5 | -0.0427 |
| 36.5 | -0.0506 |
| 39.5 | +0.0436 |

At time 80.2:

| radius | signed response |
|---:|---:|
| 74.5 | -0.0297 |

| 79.5 | +0.0280 |
| 80.5 | +0.0276 |

## Interpretation of Experiment A

The visual resemblance to an atom is real at the level of morphology: a central disturbance followed by concentric alternating response shells.

However, the shell is not stationary. It propagates outward approximately linearly in time while the central response decays.

Therefore a free linear wave medium does not by itself generate a stable atom-like object.

## Experiment B: confinement control

A finite square medium with fixed boundaries was excited at its center. The center response contains a discrete temporal spectrum and repeatedly returns because the propagating disturbance is confined by the boundary.

This demonstrates that persistent shell-like structure can arise from propagation plus confinement, but it does not establish spontaneous self-confinement.

## Result

The atom analogy is useful as a structural analogy, not yet as a physical identification.

What the experiment establishes is:

1. A localized perturbation can generate concentric spatial response bands.
2. The bands can alternate in sign, producing nodal-looking structure.
3. Propagation timing determines the apparent radius.
4. Persistence requires an additional mechanism such as confinement, reflection, or nonlinear self-trapping.
5. A stable atom-like object cannot be inferred from the visual shell alone.

## Relation-program consequence

The important object is not the shell image itself. It is the reproducible spatiotemporal response `G(r,t)` generated by an intervention.

If a stable particle-like structure is to emerge from relations alone, the next falsification test must remove externally imposed boundaries and search for self-confinement. A candidate passes only if localization, shell structure, lifetime, and spectral modes persist without an imposed container.

This is a stronger test than the previous atom-like visual comparison.

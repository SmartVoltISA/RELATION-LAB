# RELATION-INVAR-007 — Full Spatiotemporal Fingerprint

**Status:** EXECUTED / VERIFIED — POSITIVE, WITH CONTROLLED SCOPE
**Date:** 2026-09-05

## Question
Can a weak hidden relation in a continuous nonlinear medium be identified by the repeatable *shape* of its response rather than by a single one-step amplitude?

## Setup
N=40 continuous elements on a periodic ring. Nonlinear local dynamics with one weak nonlocal directed relation:

- hidden source = 11
- hidden target = 31
- K = +0.035
- intervention delta = 0.5
- 30 held-out intervention times
- response horizon = 8 steps
- score = norm of the mean signed temporal response divided by response variability

The estimator did not use the interaction matrix or hidden edge list. It ranked all 1560 ordered pairs.

## Result

| metric | result |
|---|---:|
| ordered pairs | 1560 |
| positives | 1 |
| ROC-AUC | **1.000000** |
| Average Precision | **1.000000** |
| hidden pair score | **15.4288** |
| second-ranked false pair score | **14.1750** |
| top-ranked pair | **11 → 31** |

The hidden relation was recovered as the highest-scoring pair.

## Comparison with one-step blind test

The previous blind one-step experiment with a weaker relation in N=80 gave AUC=0.974680 but AP=0.006211 and failed top-1 identification. The present test changes both the system size and K, so it is **not** a direct controlled head-to-head comparison. It tests whether adding temporal structure can recover a relation that has a coherent repeated response fingerprint.

## Interpretation

**PASS for this controlled regime.** The result supports the hypothesis that relation detection should use the full response fingerprint rather than one scalar instantaneous amplitude.

The important object is:

R_ij(r, tau) = repeatable response pattern generated by perturbing i and observing the field over space/time.

A scalar edge weight is only a projection of this object.

## Limitations

1. The field is still a synthetic model.
2. The estimator still evaluates explicitly chosen source-target probe pairs; it does not yet infer a continuous operator directly from raw field data.
3. The current result uses a relatively strong K compared with the earlier blind failure.
4. No claim of universal physical ontology follows.

## Next decisive test

Use the same fingerprint method while sweeping K downward through and below the one-step detection threshold, and test whether top-1 recovery persists because of temporal/spatial coherence. Include a fully matched null medium and preregistered detection threshold.

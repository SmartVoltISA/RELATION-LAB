# RELATION-CONTINUUM-009: Self-confinement without external boundary

Date: 2026-09-05
Status: PASS WITH SCOPE (synthetic numerical test)

## Question

Can a localized object remain spatially confined in a continuous two-dimensional medium without an imposed wall or external confining potential?

This is the direct follow-up to RELATION-CONTINUUM-008. The previous free linear wave experiment produced expanding shells but no persistent localized object.

## Model

A two-dimensional focusing saturable nonlinear field was evolved with a split-step Fourier integrator:

`i psi_t = -(1/2) Laplacian(psi) - g |psi|^2/(1 + s |psi|^2) psi`

Parameters:

`N = 128`, `L = 40`, `dx = 40/128`, `g = 4`, `s = 1`, `dt = 0.01`, `T = 100`.

Initial condition:

`psi(x,y,0) = 1.6 exp(-(x^2+y^2)/4)`

The numerical box is periodic and deliberately much larger than the localized structure. No reflecting wall, trap, or spatially varying external potential was applied. The diagnostic width remained far below half the box size, so boundary interaction is not the mechanism responsible for the observed confinement.

## Control A: linear medium

The same initial condition was evolved with `g = 0`.

The RMS radius increased from `1.414` to `16.119` by `t = 100`, with a maximum observed RMS radius of `17.516`.

This is the expected dispersive spreading control.

## Test B: nonlinear medium

With focusing saturable nonlinearity (`g = 4`), the localized excitation remained bounded and oscillatory rather than dispersing across the domain.

The conserved norm changed only at numerical roundoff level (approximately `16.08495` throughout).

## Result

**PASS WITH SCOPE.**

A continuous two-dimensional dynamical field can support a spatially localized, persistent, breathing object without an externally imposed confining boundary when the local dynamics contains a suitable saturating nonlinear interaction.

The linear control disperses strongly; the nonlinear system remains localized for the tested interval.

## What this changes

This is the first result in the current sequence where confinement is generated by the dynamics itself rather than by a wall.

The important point is not that the picture resembles an atom. The important point is that the relations encoded in the field dynamics can create a self-maintaining localized state.

The object is not stationary: its width breathes. Therefore the correct description is a localized dynamical mode, not a static particle.

## Relation-program interpretation

The sequence now has a sharper distinction:

`linear propagation -> expanding shells`

`nonlinear relational dynamics -> self-confined localized mode`

Thus propagation alone is insufficient for particle-like persistence, while propagation plus an appropriate nonlinear relation can produce self-confinement without an external container.

## Critical limitation

This does not establish that real atoms, electrons, or physical space are generated this way. The nonlinearity was specified by the model. The experiment establishes only existence of a self-confined regime in one continuous nonlinear field model.

The next falsification target is harder: determine whether the self-confined object has discrete internal modes and whether those modes can be selected or transitioned between by localized perturbations, without imposing the spectrum by hand.

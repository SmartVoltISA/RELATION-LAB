# RELATION-CONTINUUM-007 — Blind Recovery of Directed Geometry

**Date:** 2026-09-05  
**Status:** PASS (synthetic numerical test)  
**Scope:** anonymous temporal response fingerprints; no coordinates supplied to the reconstruction algorithm

## Question

Can spatial relational structure and direction be reconstructed from temporal response data when the observer is not given coordinates or the physical ordering of the elements?

This is the next falsification target after RELATION-CONTINUUM-006.

## Data generation

A periodic one dimensional medium contains `N = 40` anonymous elements. A perturbation launched at source `s` reaches target `t` through two propagation directions with different speeds:

`c_R = 0.32`

`c_L = 0.14`

with spatial sampling `dx = 1/40`, temporal step `dt = 0.002`, and observation horizon `T = 1800` steps.

For every ordered source-target pair, the temporal response was generated around the earliest propagation arrival and corrupted by Gaussian timing noise with SD `0.003`.

The observed channels were then randomly permuted.

The reconstruction algorithm received only the anonymous pairwise temporal response matrix. It was not given coordinates, the physical ordering, the generating speeds, or the adjacency structure.

## Reconstruction procedure

1. Estimate arrival time from each temporal response.
2. Build a symmetric travel-time matrix from the pairwise responses.
3. Apply classical multidimensional scaling to recover a two dimensional latent geometry.
4. Compare the recovered circular separation with the hidden physical separation.
5. Use the antisymmetric part of the response matrix to infer propagation direction.

No physical coordinates were supplied to the algorithm.

## Test A — Geometry recovery

The recovered latent circular separation was compared with the hidden circular separation using Spearman rank correlation.

| Quantity | Result |
|---|---:|
| Spearman rho | **0.998710** |
| Number of anonymous elements | 40 |
| Ordered source-target pairs | 1560 |

The geometric ordering is therefore recoverable to very high rank accuracy from response times alone.

## Test B — Direction recovery

For every unordered pair, the direction was inferred from which of the two directed responses arrived earlier.

| Quantity | Result |
|---|---:|
| Direction classification accuracy | **98.08%** |
| Number of tested unordered pairs | 780 |

Thus the directed structure can be recovered even though the observer does not know the original coordinate ordering.

## Test C — Null control

The target-channel assignments were independently permuted, destroying the coherent spatial response structure while preserving the marginal response distribution.

| Metric | Structured data | Null data |
|---|---:|---:|
| Geometry Spearman rho | **0.998710** | 0.369084 |
| Direction accuracy | **98.08%** | 50.90% |

The direction result is close to chance under the null, while the structured system remains strongly directional.

## Main result

**PASS.**

A spatially organized directed response structure can be reconstructed from anonymous temporal responses without supplying the spatial coordinates or the neighborhood graph.

The recovered object is not an ordinary list of edges. It is a latent geometry induced by response timing, together with an orientation field carried by the antisymmetric response.

## Important interpretation

This experiment does **not** show that physical space is generated by relations in nature. It shows something narrower and testable:

> Given a dynamical medium whose propagation structure is not disclosed, the structure of possible responses contains enough information to reconstruct an effective geometry and its directionality.

This is stronger than recovering a known graph because the observer is not supplied the element ordering.

## Consequence for the relation program

The current hierarchy becomes:

`observed dynamics -> response fingerprints -> relational geometry -> elements/coordinates`

This reverses the usual modelling order. Instead of starting with elements embedded in space and defining relations between them, one can start from reproducible responses and attempt to reconstruct the elements and geometry as derived objects.

## Remaining assumption

The experiment still assumes that a perturbation can be localized to a source channel and that source-target response records can be associated pairwise. The next harder test should remove even this explicit pairing and give the reconstruction procedure a collection of anonymous temporal traces with hidden source identity, requiring it to infer source, target, neighborhood, and direction jointly.

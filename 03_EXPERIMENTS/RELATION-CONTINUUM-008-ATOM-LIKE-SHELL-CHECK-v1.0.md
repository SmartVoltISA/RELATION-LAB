# RELATION-CONTINUUM-008 — Atom-Like Shell Check

**Date:** 2026-09-05  
**Status:** PASS as a morphological test; NOT an atomic-physics claim  
**Scope:** determine whether shell or cloud-like structures can arise generically from local propagation, and distinguish a propagating wavefront from a bound-state-like distribution.

## Question

The spatial reconstruction in RELATION-FUNDAMENTAL-018 visually resembles an atom: a central source surrounded by a ring or cloud. Is this morphology specifically atomic, or can it arise generically from wave propagation and response geometry?

## Experiment

Two continuum controls were simulated on the same two-dimensional periodic grid, with a localized initial disturbance.

System A: diffusion equation.  
System B: linear wave equation implemented by finite differences.

Grid: `201 x 201`.  
Wave speed parameter: `c = 0.45`.  
Diffusion coefficient: `D = 0.45`.

The response was examined through radial profiles around the source.

## Results: diffusion control

For every measured time the radial mean remained positive and peaked at the source.

| Time step | Radius of maximum radial response | Negative radial bins |
|---:|---:|---:|
| 0 | 0 | 0 |
| 200 | 0 | 0 |
| 400 | 0 | 0 |
| 600 | 0 | 0 |
| 800 | 0 | 0 |
| 1000 | 0 | 0 |
| 1200 | 0 | 0 |

Diffusion therefore produces a spreading central cloud without a propagating shell.

## Results: wave control

The wave system develops a moving radial shell and an oppositely signed inner response.

| Time step | Dominant radius | Radial peak sign | Number of positive peaks | Number of negative peaks | Center value |
|---:|---:|---:|---:|---:|---:|
| 40 | 10 | + | 1 | 1 | -0.06571 |
| 60 | 14 | + | 1 | 1 | -0.02617 |
| 80 | 19 | + | 1 | 1 | -0.01429 |
| 100 | 23 | + | 1 | 1 | -0.00903 |

For time steps 40 through 240, the dominant shell radius follows an approximately linear law. A linear fit to the measured radii gives slope `0.21988` grid units per step.

## Interpretation

A central source surrounded by a ring or cloud is therefore **not uniquely atomic**. A generic propagating wave can generate an apparently shell-like spatial structure from a localized disturbance.

This is directly relevant to RELATION-FUNDAMENTAL-018. The ring in the reconstructed geometry is consistent with a wave-propagation response geometry. Its appearance alone cannot establish an electron cloud or an atomic orbital.

However, the experiment also reveals something important for the relation program:

The shell is not an arbitrary visual artifact. It is produced by the temporal structure of propagation. A local event generates a spatially organized response whose geometry can be reconstructed from response timing.

Thus the visually atom-like object can be interpreted more conservatively as a **response shell** or **propagation shell**.

## Critical distinction from an electron cloud

An electron probability cloud is a state distribution associated with a quantum state. The wave shell in this experiment is a propagating response generated by a localized disturbance. These are different physical objects even when their pictures can look similar.

To test a genuinely atomic interpretation, the next experiment must therefore introduce a bound-state mechanism and ask whether the same relational reconstruction recovers discrete stationary modes, node structure, spectral spacing, and stability under repeated perturbation.

## Main result

**PASS for the weaker hypothesis:** shell-like geometry can emerge from relations encoded in propagation dynamics without predefined atomic structure.

**NOT established:** that the reconstructed shell is an electron cloud, an atom, or a quantum wavefunction.

## Consequence

The correct research direction is now to test whether a relation-generated response medium can produce two qualitatively different regimes:

1. propagating shells determined by causal response timing;
2. persistent bound modes determined by the internal relational dynamics.

If discrete stable modes emerge from the latter without being explicitly imposed, the connection to atomic-like structure becomes substantially stronger.
